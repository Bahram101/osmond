# Osmond CRM

## English
CRM and inventory management system built with Next.js and TypeScript.
Designed to manage clients, products, sales, visits, debts, and inventory operations. Includes role-based access, reporting, and REST API integrations.

**Tech Stack:** Next.js, TypeScript, Prisma, PostgreSQL, React Query, Reac Hook Form, Tailwind CSS.

## Русский
CRM-система для управления клиентами и складским учетом, разработанная на Next.js и TypeScript.
Позволяет управлять клиентами, товарами, продажами, визитами, задолженностями и складскими операциями. Включает ролевую модель доступа, отчеты и интеграцию с REST API.
